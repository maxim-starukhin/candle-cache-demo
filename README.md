# Candle Cache Demo

Демо кэша минутных свечей на Python и SQLite. Локальный HTTP-источник отдаёт вымышленные котировки, поэтому сценарий можно повторить без регистрации на бирже. При пересечении заданного порога программа формирует Telegram-уведомление.

## Запуск

Требуется Python 3.11 или новее. Из каталога проекта выполните:

```sh
python3 demo.py
```

На новой базе результат выглядит так:

```text
Первые две свечи: 2 свечей, HTTP-запросов: 1
  Загружено свечей по HTTP: 2
Весь интервал: 5 свечей, HTTP-запросов: 1
  Загружено свечей по HTTP: 3
Повтор интервала: 5 свечей, HTTP-запросов: 0
DEMO-USD: цена пересекла 102 вверх, закрытие 103 в 22:16 UTC.
```

Повторный запуск с той же базой читает данные из SQLite. Чтобы повторить демонстрацию с новой базой, укажите новый путь, например `python3 demo.py --db repeat.sqlite3`. Порог меняется параметром `--threshold`.

## Как это работает

Кэш хранит закрытые свечи с ключом «инструмент, длина свечи, время открытия». Запрос истории задаёт интервал `[start, end)` в секундах UTC. Кэш разбивает пропуски на интервалы, запрашивает нужные свечи через HTTP и проверяет полученные временные метки перед записью в SQLite. Цены и объёмы хранятся как точные десятичные значения.

Уведомление формируется при переходе цены закрытия через порог вверх или вниз. В обычном демо текст выводится в терминал. Для отправки задайте переменные окружения `TG_BOT_TOKEN` и `TG_CHAT_ID` своего тестового бота и запустите:

```sh
python3 demo.py --send-telegram
```

## Тесты

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют сохранение кэша между запусками, докачку интервалов, обработку пропусков, пересечение порога и запрос на отправку Telegram. Telegram API в тестах подменяется локальным ответом.
